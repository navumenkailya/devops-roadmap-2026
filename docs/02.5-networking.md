# Сети: База для DevOps (Junior/Middle)

## 1. Модель TCP/IP (Что важно знать)
* **L3 (IP):** Маршрутизация. `ping`, `traceroute`, `ip route`.
* **L4 (TCP/UDP):**
  * TCP: Надежный, 3-way handshake (SYN, SYN-ACK, ACK). HTTP, SSH, БД.
  * UDP: Быстрый, без гарантий. DNS, видео, игры.
* **L7 (HTTP/DNS):** Прикладной уровень. `curl`, `dig`, Nginx, API Gateway.

## 2. Ключевые утилиты (2025)
* `ip a` / `ip route` — замена `ifconfig`/`route`. Показывает IP и маршруты.
* `ss -tulpn` — замена `netstat`. Показывает слушающие порты и процессы.
  * `-t` TCP, `-u` UDP, `-l` Listen, `-p` Process, `-n` Numeric.
* `dig +short google.com` — проверка DNS. `@8.8.8.8` — запрос к конкретному DNS.
* `curl -I` / `curl -v` — проверка HTTP. `-I` только заголовки, `-v` полный дебаг (TLS, заголовки).
* `tcpdump` — сниффер трафика. "Тяжелая артиллерия" для дебага.
* `traceroute` — показывает путь пакета до цели (хопы).

## 3. Классический вопрос на собеседовании:
**"Что происходит, когда ты вводишь google.com в браузере?"**
1. **DNS:** Браузер проверяет кэш, затем идет к DNS-серверу. Получает IP.
2. **TCP:** Устанавливает TCP-соединение (3-way handshake).
3. **TLS:** Если HTTPS, происходит TLS handshake (обмен сертификатами).
4. **HTTP:** Браузер отправляет GET-запрос.
5. **Рендеринг:** Сервер отдает HTML, браузер строит DOM-дерево.

## 4. Проблемы и дебаг:
* **Connection refused:** Порт закрыт. Приложение не запущено или слушает `127.0.0.1` вместо `0.0.0.0`.
* **Connection timed out:** Фаервол блокирует пакеты (Security Group в AWS).
* **DNS resolution error:** Проблема в `/etc/resolv.conf` или DNS-сервере.
