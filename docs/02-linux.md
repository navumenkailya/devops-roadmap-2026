# Linux: База для собеседования (Junior/Middle)

## 1. Файловая система (FHS)
* `/` — корень.
* `/etc` — конфиги.
* `/var` — логи, БД, кэш (часто выносится на отдельный раздел).
* `/proc` — виртуальная ФС, состояние ядра и процессов.
* `/bin`, `/usr/bin` — бинарники.
* `/home` — пользователи.

## 2. Управление пакетами (Ubuntu/Debian)
* `apt update` — обновить список пакетов.
* `apt upgrade` — обновить установленные пакеты.
* `apt install <pkg>` — установить.
* `apt remove <pkg>` — удалить.
* *Best Practice:* `apt update && apt upgrade -y` при настройке сервера.

## 3. Пользователи и права
* `adduser <user>` — создать пользователя.
* `usermod -aG sudo <user>` — дать права sudo.
* `chmod`, `chown` — изменить права/владельца. (644 для файлов, 755 для директорий).
* *Best Practice:* Не работать под root. Использовать sudo.

## 4. Systemd (Управление сервисами)
* `systemctl status <service>` — статус.
* `systemctl start/stop/restart <service>` — управление.
* `systemctl enable/disable <service>` — автозагрузка.
* `journalctl -u <service>` — просмотр логов сервиса.
* *Почему systemd?* Параллельный запуск, управление зависимостями, интеграция с cgroups.

## 5. Частые вопросы на собеседовании:
* **Что такое Load Average?** (Средняя нагрузка на систему за 1, 5 и 15 минут. Показывает, сколько процессов ждут CPU).
* **В чем разница между SIGTERM (15) и SIGKILL (9)?** (SIGTERM — вежливая просьба завершиться, процесс может сохранить данные. SIGKILL — принудительное убийство, данные теряются).
* **Что такое OOM Killer?** (Out-Of-Memory Killer. Механизм ядра, который убивает процессы, если закончилась оперативная память).
* **Как посмотреть логи?** (`journalctl`, `/var/log/syslog`, `/var/log/messages`).
